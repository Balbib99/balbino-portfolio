# Portfolio personal — Balbino Martínez Rodríguez

Porfolio profesional desarrollado con React, TypeScript, Vite y Tailwind CSS para presentar mi perfil como desarrollador de software con interés en ciberseguridad, IoT, datos e IA aplicada.

## Demo

Despliegue en Vercel:

`https://portfolio-balbino.vercel.app/`

Proyecto destacado:

`https://nba-insight-eight.vercel.app/`

## Tecnologías

- React
- TypeScript
- Vite
- Tailwind CSS
- Vercel

## Funcionalidades principales

- Diseño responsive.
- Modo claro/oscuro con persistencia en `localStorage`.
- Secciones profesionales: hero, sobre mí, experiencia, proyectos, stack, formación y contacto.
- Proyecto destacado NBA Insight con caso de estudio desplegable.
- CV descargable.
- Formulario de contacto mediante `mailto`.
- Datos principales centralizados en `src/data/portfolioData.ts`.

## Cómo ejecutarlo en local

```bash
npm install
npm run dev
```

Para generar una build de producción:

```bash
npm run build
npm run preview
```

## Estructura básica

```text
src/
├── components/
├── data/
├── hooks/
├── sections/
├── App.tsx
├── main.tsx
└── index.css
```
